# Лабораторная работа № 1. Вариант 2

**Дисциплина:** Алгоритмы и структуры данных  
**Тема:** Файловые потоки ввода-вывода. Работа с текстовыми и бинарными файлами  
**Задание:** № 7, высокий уровень

## Цель работы

Научиться читать, обрабатывать и записывать данные в текстовые файлы на языке C++.

## Индивидуальное задание

В первом файле хранится k матриц размерности m × n, во втором — l матриц такого же размера. Необходимо перенести лишние матрицы из файла, в котором их больше, в третий файл и вывести содержимое всех трёх файлов на экран.

## Выполнение

Программа написана на C++ в Visual Studio. Она считывает матрицы из `first.txt` и `second.txt`, сравнивает их количество и переносит последние лишние матрицы в `third.txt`. Затем выводит содержимое трёх файлов на экран.

Например, если в первом файле четыре матрицы, а во втором две, после выполнения программы в первых двух файлах остаётся по две матрицы, а остальные две записываются в третий файл.

## Запуск

Откройте `main.cpp` в проекте C++ в Visual Studio. Поместите `first.txt` и `second.txt` в рабочую папку проекта и запустите программу сочетанием **Ctrl + F5**. Файлы должны содержать в первой строке количество матриц и их размеры, затем элементы матриц по строкам.

## Результат

Программа выравнивает количество матриц в двух файлах и сохраняет лишние матрицы в третьем файле.
